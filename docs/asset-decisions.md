# Asset library implementation decisions

- **Renderer:** stayed with the repository's React + SVG/CSS + Remotion pipeline; no new renderer or runtime animation dependency.
- **Asset sources and licenses:** 1,200 Lucide icon SVGs are from the Lucide ISC distribution; curated Simple Icons brand marks are CC0; 100 full-color Twemoji stickers retain their CC BY attribution. Shapes, textures, gradients, device frames, sample Lottie JSON, and motion recipes are original programmatic work marked CC0. Sources and trademark/attribution notes are documented in `assets/LICENSES.md`.
- **Fonts:** included 45 Latin WOFF2 families from pinned Fontsource packages, plus each upstream OFL notice. Variable faces cover weights 100–900; static families include regular 400. The bundled files are small Latin subsets (not a promise of full glyph coverage); Vazirmatn Arabic support remains available from the app's existing Fontsource package. The 15 curated family pairings are included.
- **Audio:** the app has narration text only and no audio playback/render pipeline. No SFX/music files were added. Adding audio bytes now would create a disconnected asset bucket; source-free audio generation or licensed integration belongs with a future audio track pipeline.
- **Stock media:** added server-side Pexels (photo/video), Pixabay (photo/video), and Unsplash (photo) search adapters, configured exclusively via backend environment variables. Provider result metadata and required attribution stay provider-governed; the app does not cache or relicense media.
- **Motion compatibility:** all requested motion categories are available as indexed recipe catalogs. Only the pre-existing schema values are safe to serialize into generated projects today. New values are not silently passed to Remotion; a typed asset reference and full preset renderer are a follow-up integration.
- **Gallery:** use `/assets` while the FastAPI service is running. The page uses API-backed search/category filters and previews SVGs, font faces, palette swatches, and the five rendered MP4 samples under `assets/samples/`.
- **Reproducibility:** `scripts/generate_asset_library.py` rebuilds generated assets and registry (the Lucide source tarball is fetched separately from npm); `scripts/validate_assets.py` checks local paths, required metadata, duplicate IDs, and documented license families.
